# Landing Page — Nutriê

Landing page de nutricionista criada com HTML, CSS e JavaScript puro.

## Arquivos
- `index.html` — estrutura e conteúdo
- `style.css` — identidade visual, animações e responsividade
- `script.js` — WhatsApp, menu mobile e animações
- `README.md` — instruções

## Personalização obrigatória

No `script.js`, troque:

`const WHATSAPP_NUMBER = "5500000000000";`

pelo WhatsApp real da profissional, usando o formato internacional e apenas números.

No `index.html`, personalize:
- nome da nutricionista
- CRN
- e-mail
- horários
- textos
- depoimentos
- números/estatísticas
- identidade da marca

A arte principal e a foto da seção "Sobre mim" são placeholders feitos em CSS. Para um projeto real, substitua essas áreas por fotos profissionais da nutricionista e de alimentos.

Não é necessário instalar nada. Basta abrir `index.html` ou publicar os arquivos em uma hospedagem estática.
