# NORTE Engenharia — Landing Page

Landing page profissional para pequena empresa de engenharia, criada em HTML, CSS e JavaScript puro.

A estrutura segue padrões comuns em sites atuais de engenharia/construção: portfólio visual, serviços, números de credibilidade, método de trabalho, depoimento, FAQ e CTA de orçamento.

## Personalização

No `script.js`:
- altere `WHATSAPP_NUMBER`

No `index.html`:
- nome da empresa
- CREA
- endereço
- e-mail
- telefone
- números/estatísticas
- projetos
- depoimento
- serviços
- textos

## Fotos
As fotos estão usando URLs do Pexels para deixar o protótipo visualmente pronto. Para o cliente final, prefira substituir por fotos próprias das obras, equipe e projetos.
