# Landing Page — Chaveiro Prime

Landing page responsiva criada com HTML, CSS e JavaScript puro.

## Arquivos
- `index.html` — estrutura da página
- `style.css` — visual e responsividade
- `script.js` — menu mobile, animações e links do WhatsApp

## Antes de publicar
No arquivo `script.js`, altere:
`WHATSAPP_NUMBER = "5500000000000";`

Coloque o número real no formato internacional, somente números.

No `index.html`, também substitua:
- telefone `(00) 00000-0000`
- nome "Chaveiro Prime"
- textos e avaliações fictícias
- informações de atendimento

A página não precisa de framework ou instalação de dependências.
Basta abrir `index.html` no navegador ou publicar os três arquivos em uma hospedagem estática.
