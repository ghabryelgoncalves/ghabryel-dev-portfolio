# Blade House — Landing Page Realista

Landing page de barbearia feita com HTML, CSS e JavaScript puro, agora usando fotografias reais em vez de ilustrações.

## Fotos
As fotos usadas no projeto vêm de páginas do Pexels e foram escolhidas por serem apresentadas como "Free to use" nas respectivas páginas. Para um site comercial definitivo, confira a licença vigente do Pexels e substitua pelas fotos reais do cliente quando possível.

## Personalização rápida
No `script.js`:
- altere `WHATSAPP_NUMBER`

No `index.html`:
- nome da barbearia
- endereço
- telefone
- horários
- preços
- nomes/depoimentos
- links/fotos

As imagens estão apontadas para o CDN do Pexels. Se quiser deixar o projeto 100% independente da internet, baixe as fotos autorizadas, coloque-as em `assets/images/` e troque os URLs pelos caminhos locais.
